TC-BN-10 — Known System Bottlenecks & Mitigations
⚠ Host PCIe (data ingestion)
PCIe 5.0 ×16 = 63 GB/s per GPU << HBM3 = 3350 GB/s | Ratio: 32× HBM/PCIe
Mitigation: Use in-GPU preprocessing, NVLink-based data redistribution, or PCIe switches.
⚠ CPU DRAM Bandwidth
CPU DRAM peak = 307 GB/s << HBM3 total = 8000 GB/s | Ratio: 26× HBM/DRAM
Mitigation: Pre-process data on GPU, use NUMA-local allocation, or async prefetch.
⚠ CPU FP32 vs GPU FP32
CPU FP32 turbo = 56 TFLOPS << GPU total FP32 = 268 TFLOPS | Ratio: 5× GPU/CPU
Mitigation: Offload all FP32 workloads to GPU; CPU handles orchestration only.
⚠ NVLink Fabric (GPU-to-GPU)
NVLink total BW = 1200 GB/s — not a bottleneck vs HBM but limits all-reduce in training | Ratio: 0.60× NVLink/HBM
Mitigation: Overlap all-reduce with compute; use ring-all-reduce or NCCL overlap.
⚠ Memory-Bound Kernels (low Arithmetic Intensity)
Any kernel with AI < 378 FLOP/byte is HBM-bandwidth-limited on this platform | Roofline knee = 378 FLOP/byte
Mitigation: Fuse kernels to increase arithmetic intensity; use Flash Attention.
